# Contributing

See the full guide in [CONTRIBUTING.md](https://github.com/samthakur587/Tvarant/blob/main/CONTRIBUTING.md).

## Quick start

```bash
git clone https://github.com/samthakur587/Tvarant.git
cd Tvarant
pip install -e ".[dev,docs]"
pytest tests/ -v
```

## Pull requests

1. Fork → feature branch → changes + tests
2. Update `CHANGELOG.md` under **Unreleased**
3. Open PR using the template
4. Wait for CI (build, test, docs, lint)

## Code of conduct

All contributors must follow our [Code of Conduct](https://github.com/samthakur587/Tvarant/blob/main/CODE_OF_CONDUCT.md).

## Security

Report vulnerabilities via [GitHub Security Advisories](https://github.com/samthakur587/Tvarant/security/advisories/new) —
see [SECURITY.md](https://github.com/samthakur587/Tvarant/blob/main/SECURITY.md).
